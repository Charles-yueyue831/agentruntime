本周观察

记忆随任务在应用之间流动

周一的 Hy Memory 2.0 面向多种工具共享记忆。到周五，Claude Duet 把已有记忆和应用连接带到了新的个人智能体中。

从执行操作到核对结果

ChatGPT Chrome 和 Marvis 分别处理网页与桌面操作。WorkForge 把关注点放到执行之后，用职场任务检验交付结果。

机器人报道关注了三个不同环节

Dream API 提供控制接口，智元开放具身推理数据，特斯拉披露产线进展。三条新闻分别对应如何下达任务、如何评估决策和如何制造硬件。

预览、传闻与发布

周二出现的 Aurora 很快从模型列表消失。周三关于 Anthropic 新模型的消息来自媒体报道。两项都与周五已开放候补申请的 Duet 分开统计。
