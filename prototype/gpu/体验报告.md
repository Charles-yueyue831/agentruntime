# GPU 交互原型用户体验记录（正常速度高清版）

2026-09-15，独立浏览器体验当前在线原型。使用正常操作速度，显示鼠标移动与橙色点击反馈。录制覆盖 14 个操作节点，最后一个操作节点位于 44 秒。

本次重点展示：资源类型选为 GPU → 展开资源组名称并选择 → 停留 3.5 秒 → 系统盘选择 10 Gi。

## 体验结论

模拟购买、资源准备、按资源组名称创建工具、启动实例、暂停与恢复、停止和释放的主流程走通。释放完成后，资源组显示“可用·空闲中”数量为 1。

已确认新版不再显示“模拟支付成功，GPU 资源准备中。”和“演示：完成资源准备”。通过刷新图标展示资源准备完成。

## 用户视角观察

- 资源组名称贯穿工具创建及关联列表，便于核对。
- 创建工具后可进入实例列表启动，启动前能够看到资源可用额度。
- 停止后需手动点击“演示：GPU 释放完成”，等待过程缺少说明。建议正式流程自动处理释放并显示进度。
- 新购资源生效时间显示当天 08:00，与实际体验时间不一致，建议明确生效时刻。
- 实例表格操作区需要横向滚动，实例 ID 可能离开视野，建议固定实例 ID 列。

## 体验范围

本次仅覆盖成功主流程，未验证余额不足、资源到期、跨地域及全部续退费分支。购买与实例操作均为原型模拟，不产生真实交易或 GPU 实例。当前用户浏览器数据未改动。
