## 演示内容

- 预热任务：创建任务、设置闲置阈值、查看详情、编辑策略及手动卸载确认。
- 自动预热：配置 TCR 实例、命名空间和镜像匹配规则，创建策略、查看详情与停用说明。
- 自动卸载：配置适用镜像、闲置超时和最近最少使用优先卸载，创建及编辑业务级策略。
- 预热任务监控：查看核心指标、按来源筛选、切换时间粒度、查看趋势与刷新。

## 播放说明
